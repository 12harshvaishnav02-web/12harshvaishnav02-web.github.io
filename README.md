# Harsh Vaishnav — Responsive Portfolio

## Add your personal background photo
1. Put your photo in the `assets` folder.
2. Name it exactly `your-photo.jpg`.
3. It will appear as a fixed background image aligned to the right. The text and details scroll; the image stays stationary. On desktop, content is kept to the left to leave space for the photo; on mobile, content uses the full frame to avoid cramped text.
4. For best results, use a high-resolution image with your subject toward the right side. The page has a black overlay to keep text readable.

If you prefer another filename, change `background` in `style.css`:
`background:#080808 url("assets/your-photo.jpg") no-repeat right center;`

## Run
Extract the ZIP, open the folder in VS Code, then open `index.html` with Live Server.
